# 하네스 중립 어휘

이 문서는 `plugins/` 아래 스킬을 여러 코딩 에이전트 하네스에서 함께 유지하기 위한 작성자용 정본이다.
실행 시 자동으로 로드되는 문서가 아니므로, 스킬에 필요한 지시는 해당 `SKILL.md`에도 직접 적는다.

원칙은 하네스 이름이 아니라 **현재 턴에 실제로 제공된 역량**을 기준으로 분기하는 것이다. 특정 도구가
없다는 이유로 단계를 조용히 생략하지 않는다. 같은 목적을 달성하는 폴백을 실행하거나, 결과를 바꾸는
결정만 사용자에게 확인한다.

| 동작 | 표준 문구 |
|---|---|
| 선택지 묻기 | 구조화 질문 도구가 있으면 사용한다. 없으면 추천안을 첫 번째에 둔 번호 목록으로 대화에서 묻는다. |
| 계획 승인 관문 | 계획 모드 진입·이탈 도구가 있으면 즉시 사용한다. 없으면 구조화 질문 도구 또는 대화의 명시적 승인으로 같은 관문을 만든다. |
| 작업 단계 추적 | 작업 추적 도구가 있으면 단계와 상태를 기록한다. 없으면 대화나 작업 문서의 짧은 체크리스트로 추적한다. |
| 다른 스킬 이어 부르기 | 스킬 호출 도구가 있으면 대상 스킬을 호출한다. 없으면 사용 가능한 스킬 목록에서 대상 지침을 찾아 읽고 현재 에이전트가 그대로 수행한다. 대상 지침도 없으면 사용자에게 알린다. |
| 병렬 조사 | 워크플로 실행 도구가 있으면 기존 워크플로를 쓴다. 없고 서브에이전트 위임이 가능하면 독립 작업을 병렬 배분한다. 둘 다 없으면 같은 조사 각도를 순차 실행한다. |
| 웹 조사 | 현재 제공된 웹 검색·페이지 읽기 도구를 사용하고, 실제로 연 원문 URL을 결과에 남긴다. |
| 인자 받기 | 호출과 함께 전달된 자연어 인자를 사용한다. 인자가 없고 결과가 달라지는 필수 입력만 사용자에게 묻는다. |
| 스킬 디렉터리 | `$SKILL_DIR` 같은 셸 변수를 가정하지 않는다. 현재 `SKILL.md`가 들어 있는 디렉터리를 기준으로 상대 경로를 해석하고, 셸 실행 전 절대 경로로 바꾼다. |
| 세션 기록 읽기 | 현재 대화를 1차 입력으로 사용한다. 하네스가 세션 로그 위치와 형식을 제공할 때만 파일을 보강 입력으로 읽고, 형식을 추측하지 않는다. |
| 프로젝트 지침 파일 | 현재 하네스가 읽는 프로젝트 지침 파일을 우선한다. 일반적으로 `AGENTS.md` 또는 `CLAUDE.md`이며, 현재 파일에서 repo root까지 가장 가까운 적용 범위를 따른다. |
| 하네스 전역 지침 | 현재 하네스가 실제로 로드한 전역 지침 위치만 사용한다. 다른 하네스의 홈 디렉터리를 있다고 가정하지 않는다. |
| 개인 비공유 지침 | 현재 하네스가 개인 비공유 프로젝트 지침을 공식 지원할 때만 그 위치를 쓴다. 지원 근거가 없으면 `AGENTS.local.md` 같은 파일을 지어내지 말고 사용자에게 저장 위치를 확인한다. |
| 프로젝트 스킬 설치 위치 | 기존 프로젝트 관례를 우선한다. 새 위치라면 Codex 계열은 `.agents/skills/`, Claude Code 계열은 `.claude/skills/`를 사용한다. 양쪽 공유가 목적이면 한 디렉터리를 정본으로 두고 다른 쪽은 심볼릭 링크로 연결할지 사용자에게 확인한다. |

## 고정 패턴

스킬 본문에서는 아래 문구를 가능한 한 그대로 쓴다.

### 구조화 질문

> 구조화 질문 도구가 있으면 사용한다. 없으면 추천안을 첫 번째에 둔 번호 목록으로 대화에서 묻는다.

### 스킬 연결

> 스킬 호출 도구가 있으면 대상 스킬을 호출한다. 없으면 사용 가능한 스킬 목록에서 대상 지침을 찾아 읽고 현재 에이전트가 그대로 수행한다.

### 서브에이전트

> 서브에이전트 위임이 가능하면 독립 검증을 맡긴다. 불가능하면 같은 체크리스트로 두 번째 읽기 패스를 직접 수행한다.

### 프로젝트 지침

> 현재 하네스가 읽는 프로젝트 지침 파일(`AGENTS.md`, `CLAUDE.md` 등) 중 현재 경로에 가장 가까운 적용 범위를 따른다.

## 검증용 금지 패턴

새 스킬과 수정한 스킬 본문에는 아래 패턴을 남기지 않는다.

- 실행 시 치환된다고 가정하는 `$ARGUMENTS`
- 실제 환경변수처럼 보이는 `$SKILL_DIR` 또는 `${SKILL_DIR}`
- 폴백 없이 단독으로 쓰인 `AskUserQuestion`, `Workflow`, `Skill` 도구 지시
- 현재 하네스에서 지원 여부를 확인하지 않은 `AGENTS.local.md` 같은 경로
