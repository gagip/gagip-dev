# design

디자인 시스템 결정을 문서화하는 스킬이다.

## 스킬

| 스킬 | 설명 | 트리거 예시 |
|---|---|---|
| `design-md` | 코드에서 디자인 결정을 추출해 `DESIGN.md` 생성 | "디자인 시스템 문서 만들어줘" |

## 에이전트

| 에이전트 | 설명 | 트리거 예시 |
|---|---|---|
| `design-critic` | 화면(스크린샷·UI 코드)을 첫인상 → 원인 추적 → 빼는 수정 순으로 비평하고 숫자가 붙은 수정안을 보고하는 읽기 전용 에이전트 | "이 화면 디자인 컨펌해줘" |
