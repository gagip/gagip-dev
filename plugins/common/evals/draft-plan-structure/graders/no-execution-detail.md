저장된 계획서 파일 내용을 확인하라.

통과 조건:
- `## 3. 요구사항`(또는 그에 대응하는 절)의 설계 판단이 나열식 문단이 아니라 `결정 | 이유` 형태의 표로 정리되어 있다.
- 계획서 안에 완성된 코드 diff, 전체 코드 전문(수십 줄 이상의 실제 구현 코드 블록), 또는 "1단계: 파일 A 수정 → 2단계: 파일 B 수정 → ..." 식의 파일별 작업 순서표가 포함되어 있지 않다. 참고용으로 기존 코드 몇 줄을 인용하는 것은 허용되지만, 새로 작성할 구현 코드 전문을 담으면 안 된다.

둘 중 하나라도 위반하면 실패로 판단하라.
