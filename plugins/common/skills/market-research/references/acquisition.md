# 원문 확보: 접근 단계와 반자동 캡처

## 목차
- 접근 단계 정하기
- 하지 않는 것
- 반자동 캡처 맡기기
- 캡처가 잘못 찍히는 경우
- 출처별로 확인된 사실

## 접근 단계 정하기

출처 하나에 단계 하나를 정한다. 같은 출처 안에서도 검색 결과 페이지와 글 본문의 단계가 다를 수 있으니 따로 본다.

| 확인 | 결과 | 다음 |
|---|---|---|
| `probe_access.py` curl verdict | `본문 있음` | 자동. 본문을 받아 저장한다 |
| | `로그인·차단 화면 의심` 또는 `받기 실패` | 브라우저 도구로 열어 본다 |
| 내장 브라우저·브라우저 확장으로 열기 | 열리고 본문이 보인다 | 브라우저 도구. 페이지 글자를 저장한다 |
| | "이 사이트는 열 수 없다" 같은 정책 차단, 로그인 요구 | 반자동 캡처 |
| 사람이 브라우저로 열기 | 회원 전용·삭제·비공개 | 제외. `capture_log.tsv`의 `skip` 수로 센다 |

`로그인·차단 화면 의심`은 글자 수와 낱말로 짐작한 것이다. 저장본을 열어 실제 화면을 한 번 본다.

## 하지 않는 것

- 사이트 내부 API, 앱 전용 주소, 모바일 주소로 바꿔 다시 받기
- 쿠키·로그인 정보를 스크립트에 넣기, 로그인 자동화
- 봇 차단·캡차 넘기기, 자동 스크롤·자동 캡처 반복
- 브라우저 도구가 막은 사이트를 다른 브라우저 도구로 다시 열기

이 중 하나가 필요해 보이면 그 출처는 반자동 캡처로 내린다.

## 반자동 캡처 맡기기

사람이 할 일은 "브라우저에서 글 읽기·스크롤 + 엔터"뿐이게 만든다.

1. `shortlist.tsv`를 질문(`group`) 순으로 정렬해 둔다. 같은 주제를 이어 읽어야 사람이 덜 지친다.
2. 사람에게 줄 것: 명령 한 줄, 키 설명(엔터 = 찍기, n = 다음, s = 건너뛰기, q = 끝내기, 다시 실행하면 이어서),
   "글이 길면 스크롤하며 여러 장 찍는다", "댓글도 찍는다", "첫 글 한 장 찍으면 알려 달라".
3. 첫 장을 직접 열어 확인한다. 브라우저 창이 아니라 다른 앱이 찍혔으면 멈추고 원인을 고친다.
4. 끝나면 `capture_log.tsv`에서 `saved`·`skip`·`empty` 수를 센다. `skip`이 많으면(회원 전용 등) 그 출처의 결론 범위가 좁아진다.
   `empty`(찍지 않고 넘긴 글)를 다시 찍으려면 로그에서 그 줄을 지우고 다시 실행한다. Ctrl-C로 끊긴 글은 `partial`로 남아 다음 실행 때 이어 찍는다.

명령 실행 위치:
- 사용자가 직접 터미널에 붙여 넣는 것이 기본이다. `input()`으로 키를 받으므로 백그라운드 실행으로는 안 된다.
- 하네스가 사용자 터미널에 명령을 띄우는 도구를 주더라도, 그 도구가 비ASCII 경로나 세션 밖 작업 경로를 거부할 수 있다.
  그때는 ASCII 경로의 심볼릭 링크(예: `/tmp/<이름>`)로 작업 폴더를 가리키게 하고 그 경로로 실행한다.
- 첫 실행에서 macOS가 화면 기록 권한을 물으면 터미널 앱을 허용해야 한다.

## 캡처가 잘못 찍히는 경우

- 화면 좌표로 찍으면(`screencapture -R`) 그 위에 덮인 창이 찍힌다. `capture_helper.py`는 창 번호(`-l`)로 찍으므로 가려져 있어도 된다.
- 브라우저 창을 최소화하면 창 목록에서 빠져 "창이 없다"가 나온다.
- 브라우저 창이 여러 개면 가장 큰 일반 창을 찍는다. 다른 창이 더 크면 그 창을 닫거나 줄인다.
- 다른 브라우저를 쓰면 `--app`에 앱 이름(예: `Safari`, `Arc`)을 준다.

## 출처별로 확인된 사실

| 출처 | 검색 결과 | 글 본문 | 비고 |
|---|---|---|---|
| 네이버 카페 | 통합검색 카페 탭은 curl로 받아짐(`naver_cafe`) | 내장 브라우저·브라우저 확장 모두 정책 차단 → 반자동 캡처 | 카페 내부 API 호출은 도구 분류기가 접근 우회로 거부한다. 회원 전용 글이 선별 후보의 절반을 넘을 수 있어 후보를 넉넉히 고른다 |
| 네이버 블로그 | 통합검색 블로그 탭은 curl로 받아짐(`naver_blog`) | 출처 접근 확인으로 정한다 | |
| 네이버 지식iN | 통합검색 지식iN 탭은 curl로 받아짐(`naver_kin`). 한 페이지 후보가 적다 | 출처 접근 확인으로 정한다 | 답변 링크는 질문 주소로 묶인다 |

새 출처를 확인하면 이 표에 한 줄 더한다. 날짜가 지나면 막힘 여부가 바뀔 수 있으니, 표는 출발점으로만 쓰고 2단계 확인은 매번 한다.
