# 분류 기준

분류·재판정 서브에이전트에게 이 파일 경로를 그대로 넘긴다. 맞는 값이 없으면 새 이름을 만들고 요약 파일에 정의를 적는다.

## 업무 종류 (work_type)

| 값 | 포함 |
|---|---|
| 기획 | 제품 방향, 명세, 계획서, 의사결정 문서, 기술 문서 |
| 디자인 | 화면 시안, 디자인 시스템 |
| 개발 | 코드 구현, 버그, 리팩터, 빌드, 서버·인프라 운영 |
| QA·출시 | 회귀 검증, 실기기 확인, 스토어 제출 |
| 조사 | 자료·레퍼런스·경쟁사·법무·연구 자료 조사 |
| 문서관리 | 문서 이동·정리·위키 |
| 업무운영 | 일일·주간 기록, 스탠드업, 할 일 목록, 회의록, 예약 루틴 |
| 대외커뮤니케이션 | 메일, 보고, 외부 미팅 준비 |
| 에이전트환경 | 스킬·지침·메모리·훅·MCP·플러그인 제작과 수정, 회고 |
| 환경설정 | 로컬 도구·계정·기기 설정 |
| 지휘·세션관리 | 하위 세션을 띄우고 머지·통제하는 세션 |
| 기타 | 분류가 애매한 짧은 세션 |

두 종류가 섞이면 주된 것 하나를 work_type 에, 나머지를 secondary 에 둔다.

## automated

사람이 직접 연 세션이 아니면 적는다: `예약`(예약 작업이 연 세션), `이어받기`(자동으로 이어받은 세션), `평가`(스킬 테스트·프로브처럼 사람 업무가 아닌 실행). `평가`는 집계에서 빠진다.

## 단계 (stage)

요청, 의도확인, 맥락수집, 조사, 계획서, 계획검토, 시안, 사용자결정, 구현, 자체검증(테스트·빌드·실기기·화면), 독립리뷰, 문서작성, 시각보고, 커밋, PR, 머지, 게시(외부 도구에 올림), 회고, 메모리저장.
이 순서를 우선 쓰고, 꼭 필요할 때만 새 단계를 만든다.

## 잘못의 종류 (kind)

| 값 | 포함 예 | 제외 예 |
|---|---|---|
| 지시오해 | 요청한 파일 말고 다른 파일을 고침 · "요약"을 "전문 번역"으로 이해 | 요청이 모호해 물었어야 했던 경우(→ 질문부족·임의결정) |
| 범위넘김 | 시키지 않은 리팩터를 함께 함 · "계획만"인데 코드를 고침 | 사용자가 나중에 범위를 넓힌 경우(교정 아님) |
| 검증누락·미검증주장 | 테스트를 안 돌리고 "통과"라고 보고 · 화면을 안 보고 "고쳤다" | 검증했는데 결과 해석이 틀림(→ 사실오류·확인안함) |
| 사실오류·확인안함 | 없는 옵션을 있다고 함 · 파일을 안 읽고 내용을 단정 | 문장이 어려워 못 알아들음(→ 설명어려움) |
| 내용부족·결함 | 보고에 핵심 수치가 빠짐 · 코드에 버그·품질 문제 | 모양만 다름(→ 산출물형식) |
| 설명어려움 | 전문어·약어를 안 풀어 이해 못 함 · 맥락 없이 선택지만 던짐 | 정해 둔 표기 규칙 위반(→ 표기규칙) |
| 표기규칙 | 정해 둔 언어·제목 어미·금지 낱말을 어김 | 규칙은 없지만 읽기 어려움(→ 설명어려움) |
| 산출물형식 | HTML을 원했는데 마크다운으로 줌 · 표 대신 줄글 | 내용이 빠짐(→ 내용부족·결함) |
| 저장위치·경로 | 정해 둔 폴더가 아닌 곳에 저장 · 틀린 브랜치에 커밋 | 경로를 잘못 알고 단정(→ 사실오류·확인안함) |
| 과잉질문·멈춤 | 정한 일인데 다시 물음 · 진행 중 불필요하게 멈춤 | 정말 사용자 결정이 필요한 질문 |
| 질문부족·임의결정 | 갈림길을 묻지 않고 정해 버림 | 사용자가 맡긴 범위 안의 결정 |
| 도구·환경오류 | 명령 실패를 반복 · 권한·경로 문제로 막힘 | 에이전트 판단 잘못(→ 해당 종류) |
| 진행느림·비효율 | 같은 조회를 반복 · 병렬로 할 일을 하나씩 | — |
| 기타 | 위에 안 맞는 것 | — |

## 원인 (cause) — 재판정에서만

| 값 | 뜻 | 더 적는 것 |
|---|---|---|
| 규칙있음_어김 | 그 교정 전에 같은 실수를 막는 규칙이 지침·메모리·스킬에 있었다 | rule_place, rule_file, rule_text |
| 규칙없음 | 막는 규칙이 없었고, 상식으로도 피하기 어려웠다 | — |
| 스킬미호출 | 그 일을 맡는 스킬이 있었는데 부르지 않았다 | missing_skill |
| 판단오류 | 규칙·스킬 문제가 아니라 그 자리의 판단이 틀렸다 | what 에 어떤 판단이었는지 |
| 도구한계 | 도구가 할 수 없는 일이었다 | what 에 도구 이름 |

rule_place: `상시지침`(매 세션 자동으로 실리는 지침·메모리 목록), `상세파일`(필요할 때 읽는 지침 파일), `메모리`(개별 메모리 파일), `스킬`(SKILL.md·그 references), `없음`.
rule_file 은 절대 경로를 적는다. 스킬이면 `.../skills/<이름>/SKILL.md`.
