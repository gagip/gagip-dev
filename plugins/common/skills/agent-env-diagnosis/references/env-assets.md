# 살펴볼 에이전트 환경 자산

`env_scan.py`는 경로를 추측하지 않는다. 지금 세션에 실제로 실린 지침과 사용자가 쓰는 폴더를 아래 순서로 찾아 인자로 넘긴다.

| 자산 | 찾는 법 | 인자 |
|---|---|---|
| 상시 지침 | 지금 컨텍스트에 자동으로 실린 지침 파일(전역 지침, 프로젝트 `CLAUDE.md`·`AGENTS.md`, 메모리 목록 파일). 심볼릭 링크는 스크립트가 실제 파일로 풀어 중복을 뺀다 | `--always 파일...` (생략하면 두 도구의 전역 지침만) |
| 상세 파일 | 상시 지침이 "~ 전에 읽는다"고 가리키는 파일이 모인 폴더 | `--details 폴더...` |
| 메모리 | Claude `settings.json`의 `autoMemoryDirectory`, 또는 지침이 가리키는 메모리 폴더. 하위 폴더(보관함)는 세지 않는다 | `--memory 폴더` (생략하면 settings.json 값) |
| 훅 | Claude `settings.json`의 `hooks`, Codex `hooks.json`, 설치된 플러그인의 `hooks/` | `--hooks 파일...` (생략하면 앞의 두 파일) |
| 스킬 | 1단계 `measure.py`가 센다 | — |
| 서브에이전트 정의 | 1단계 `measure.py`의 서브에이전트 종류 표 | — |

## 읽는 법

- **상시 지침 바이트**: 매 세션 컨텍스트를 그만큼 먼저 쓴다. 규칙 줄 수는 목록 줄(`-`, `1.`)을 센 근사치다.
- **상세 파일 연 세션 수**: 그 파일이 "읽어야 하는 상황"의 세션 수와 맞대 본다(예: 커밋 전에 읽는 파일이면 1단계에서 커밋·PR 스킬을 부른 세션 수).
- **안 열린 메모리**: 목록 파일이 매 세션 실리면 한 줄 요약만으로 쓰였을 수 있다. 보관 후보로만 넘기고 바로 지우지 않는다.
- **훅 발동**: 기록에는 사용자가 설정한 훅과 앱·플러그인이 넣은 안내(예: 파일을 쓴 뒤 미리보기 안내)가 같은 모양으로 남는다. 숫자를 인용하기 전에 기록 원문 한 건을 열어 무엇인지 확인한다.

"열었다"는 그 세션의 도구 호출 인자에 `<부모 폴더>/<파일 이름>`이 나온 것이다. 고치려고 연 경우도 들어간다.
