# 서브에이전트 지시문

`{OUT}`은 산출물 폴더 절대 경로, `{NN}`은 묶음 번호(두 자리), `{TAXONOMY}`는 `references/taxonomy.md` 절대 경로로 바꿔 넘긴다.
묶음마다 서브에이전트 하나를 한 번에 띄운다. 임시 파일을 쓸 일이 있으면 이름에 묶음 번호를 붙이게 한다(같은 이름을 서로 덮어쓴 사례가 있다).

## 1차 분류 (chunk_{NN})

```
한 사용자가 AI 코딩 에이전트와 나눈 세션 기록 묶음을 분류한다. 목적은 진단이다: 어떤 일을 어떤 단계로 하고, 어디서 사용자가 에이전트를 고쳤는지. 개선안은 쓰지 않는다.

입력: {OUT}/chunks/chunk_{NN}.md — 세션마다 `### <키> | 작업 폴더 | 시작~끝 | 제목 | 압축·중단 수 | 분기=<원래 세션>`, 스킬·도구·쓴 파일, 사용자 발화 목록. 끝까지 전부 읽는다(나눠 읽기). 기준: {TAXONOMY}. 다른 파일은 읽지 않고 명령을 실행하지 않는다.

세션마다:
- work_type, secondary, automated: 기준 파일대로.
- stages: 실제로 일어난 단계를 순서대로.
- corrections: 사용자가 에이전트의 잘못을 지적·교정·거절·되돌린 발화 후보. 각 항목 {quote(원문 80자 이내, 발화에서 그대로 복사), stage}. 앞 제안에 동의하며 다음 지시를 한 발화, 새 요청, 단순 선호 추가는 넣지 않는다. 확실하지 않으면 넣는다(다음 단계에서 앞 응답과 함께 다시 판정한다).
- outcome: 완료 | 중단 | 불명.

출력 1: {OUT}/classified/chunk_{NN}.json — 배열, 세션당 {id(헤더의 키 그대로), work_type, secondary, automated, stages, corrections, outcome}. 입력의 모든 세션을 빠짐없이 넣는다. 쓰기 전에 `### ` 헤더 수와 배열 길이가 같은지 센다(파일 앞부분만 처리하고 끝낸 사례가 있다).
출력 2: {OUT}/classified/chunk_{NN}_summary.md — 기간, 업무 종류별 세션 수, 새로 만든 값의 정의, 업무별 대표 흐름 2~3개(세션 키 근거).
마지막 답변: 세션 수와 업무 종류별 수만 5줄 이내.
```

## 교정 재판정 (ctx_{NN})

```
1차 분류가 고른 교정 후보를 다시 판정한다. 각 줄에는 사용자 발화(user_correction), 그 앞 사용자 요청, 바로 앞 에이전트 응답 끝부분, 그 사이 도구 호출, 그때까지 부른 스킬, 그때까지 연 .md 파일이 들어 있다.

입력: {OUT}/context/ctx_{NN}.jsonl. 기준: {TAXONOMY}.
규칙 확인에 읽을 곳: {RULE_SOURCES}
위 파일만 읽는다. 파일을 고치거나 쓰는 명령은 실행하지 않는다. 규칙은 전부 읽지 말고 교정 주제의 낱말로 찾는다: 검색 도구가 있으면 그것을, 없으면 읽기 전용 `grep -rn`·`rg`를 쓴다(검색 없이 상시 지침만 보면 메모리·스킬의 규칙을 놓친다). 교정 날짜 뒤에 생긴 규칙은 "있었다"로 치지 않는다(파일 안 날짜·git 이력을 모르면 현재 문장 기준으로 판정하고 what 끝에 "(도입 시점 미확인)").

줄마다:
- real: 에이전트의 잘못을 고친 발화면 true. 앞 제안에 동의하며 다음 지시를 한 것, 새 요청, 취향 추가는 false 와 reason.
- kind, stage: 기준대로.
- cause, rule_place, rule_file, rule_text(규칙 문장 요지 한 줄), missing_skill: 기준대로. 해당 없으면 null.
- what: 무엇이 잘못됐는지 한 줄.

출력: {OUT}/judged/judged_{NN}.json — 배열, 줄당 {n(입력의 n 그대로), real, reason, kind, stage, cause, rule_place, rule_file, rule_text, missing_skill, what}. 입력의 모든 줄을 넣는다.
마지막 답변: 줄 수, real 수, cause 별 수만 5줄 이내.
```

`{RULE_SOURCES}`에는 env_scan 에 넘긴 상시 지침·상세 파일 폴더·메모리 폴더와 설치된 스킬 폴더를 줄 단위로 적는다.
