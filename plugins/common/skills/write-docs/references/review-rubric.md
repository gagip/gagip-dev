# write-docs 검수 기준

문서를 쓴 맥락을 모르는 상태에서 문서와 사실표만 읽고 채점한다. 항목마다 통과·미통과와 문서 인용을 답한다. 막힌 곳은 고칠 문장을 제안한다.

## 항목

| # | 기준 | 통과 조건 |
|---|---|---|
| 1 | 독자가 되묻지 않고 할 일을 할 수 있는가 | 독자·목적 줄의 일을 문서만으로 할 수 있고, 뜻을 되물을 문장이 없다 |
| 2 | 독자가 모르는 말이 풀려 있는가 | 본문의 전문어·약어·내부 이름이 처음 나올 때 풀려 있다 |
| 3 | 구체적인가 | 대상·값·행동이 없는 추상 문장이 없다 |
| 4 | 쓸모없는 정보가 빠졌는가 | 독자가 판단·행동에 쓰지 않을 배경, 작업 경위, 되풀이가 없다 |
| 5 | 단정과 미확인이 나뉘어 있는가 | 근거 없이 단정한 듯한 문장이 없고, 미확인 사실은 「확인 필요」에 확인 대상과 함께 있다 |
| 6 | 문서 종류의 역할을 지켰는가 | 기능 명세는 의도와 상황별 동작이 있고, 기획 계획서는 구현 방식이 없고, 결정 문서는 상태가 내용과 맞고, 제품 방향 문서는 확정·가설·미합의가 근거와 맞고 비목표가 있다 |
| 7 | 단정 문장이 사실표와 맞는가 | 본문의 단정 문장이 사실표의 「직접 봄」 줄에 있다. 없는 문장은 모두 인용한다 |

## 답 형식

```
#<번호> 통과 | 미통과
근거: "<문서에서 인용한 문장>"
고칠 문장: <미통과일 때>
```
