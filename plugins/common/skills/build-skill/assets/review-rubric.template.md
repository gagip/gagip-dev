## 채점 방법

검수 에이전트에게 다음 세 가지만 준다. 대화 맥락과 스킬 본문은 주지 않는다.

1. 산출물 경로
2. 이 기준 파일 경로
3. 사용자 요청 원문

항목마다 아래 형식으로 답하게 한다. 근거 없는 통과는 인정하지 않는다.

```
#<번호> 통과 | 미통과
근거: "<산출물에서 인용한 문장>"
```

## 최종 판정

채점표는 참고 자료다. 최종 통과 여부는 사람이 결과물과 채점표를 함께 보고 정한다.
