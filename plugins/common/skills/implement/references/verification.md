# 검증 증거와 이해 인계

계획서·이슈에 있는 완료 조건을 그대로 쓴다. 별도 조건 목록이나 단계 상태 문서는 만들지 않는다.
검증 로그는 프로젝트가 정한 저장소 밖 작업 폴더에 둔다. 계획서 없는 작은 작업도 필요한 조건만
명령 인자로 전달한다. 아래 `scripts/verify.py`는 이 스킬 디렉터리 기준 경로다.

## 실행과 확인

```bash
python3 scripts/verify.py run --repo <레포> --evidence <작업폴더>/evidence --condition '<완료 조건>' -- python3 -m unittest discover
python3 scripts/verify.py check --repo <레포> --evidence <작업폴더>/evidence --condition '<완료 조건>'
```

- `run`은 실제 명령·종료 코드·로그·시각·HEAD·실행 전후 코드 지문을 남긴다. 명령은 레포 루트에서
  실행하며 셸 확장은 하지 않는다. 실패·시간 초과·실행 불가·중단은 통과가 아니다.
- `check`에는 계획서·이슈의 완료 조건을 `--condition`으로 모두 전달한다. 조건 하나당 반복할 수
  있다. 누락·실패·실행 중·로그 변조·검증 이후 코드 변경이면 종료 코드 1이다. 기록이 있는 조건만
  골라 검사하거나, 실패한 조건을 빼서 완료하지 않는다. 검사 대상의 적절성은 리뷰에서도 확인한다.
- 같은 조건은 동시에 실행하지 못한다. 재실행을 시작하면 이전 성공은 즉시 무효화된다.
- 문서·코드·테스트 정리 뒤 최종 검증하고, **push·PR 및 완료 보고 전에 `check`를 실행한다.**
  실패를 통과로 보고하거나 자동 검증을 사람 확인으로 바꾸지 않는다.

지문은 Git 추적 파일과 무시되지 않은 미추적 파일의 내용·실행 권한·심볼릭 링크를 본다.
커밋·스테이징만 바뀌고 내용이 같으면 유효하다. 첫 버전은 저장소 전체를 보므로 문서만 바뀌어도
재검증한다. 빌드 산출물은 기존 무시 규칙을 따르고, 검증 출력은 작업 폴더에 둔다.
무시된 설정·외부 서비스·데이터는 포함하지 않으므로 의존 환경을 보고하고 변경되면 재검증한다.
서브모듈 등 식별하지 못하는 경로는 실패로 남긴다. 이 도구는 macOS·Linux의 파일 잠금을 사용한다.

종료 코드 0은 명령 성공이지 요구사항 충족의 증명은 아니다. 무관한 명령이나 약해진 기대값으로
통과시키지 않는다. 중요한 버그 수정은 결함을 되살렸을 때 테스트가 실패하는지 확인하고 되돌린다.
실행 기록은 서명된 증명이 아니며, 도구를 건너뛰는 행동을 외부에서 강제 차단하지 않는다.
검사와 완료 조건의 대응·증거의 신뢰성은 코드 리뷰 대상이다. 로그에 비밀 값이 있을 수 있으므로
공개 레포에 커밋하거나 외부에 공유하지 않는다.

## 사람 확인

자동 검사로 대신할 수 없는 조건은 계획서·이슈에 `사람 확인`으로 표시한다. 실제 사용자 확인을
받은 뒤에만 출처와 관찰을 기록한다. AI 자기판정이나 화면 관찰을 사용자 확인으로 바꾸지 않는다.

```bash
python3 scripts/verify.py confirm --repo <레포> --evidence <작업폴더>/evidence --condition '<완료 조건 — 사람 확인>' --source '<실제 확인 발언·기록 링크>' --observation '<관찰한 결과>'
```

미확인이 남으면 구현 결과와 남은 조건을 먼저 인계하고 전체 달성으로 보고하지 않는다. 확인을
받기로 합의한 시점에 받는다. 확인 출처의 진실성은 기계가 증명하지 못한다.

## 짧게 설명

최종 보고와 PR 본문에 바뀐 동작·핵심 결정·확인한 것·남은 한계를 연결해 쓴다. 구체적인 입력
하나의 이전/이후, 방법을 고른 이유, 조건별 증거와 환경, 미확인 범위를 담는다. 단순 수정은 한두
문장이면 충분하고 별도 설명 문서를 만들지 않는다. 설명은 실제 코드·실행 증거와 대조한다.

설명 생성은 사용자 이해 완료가 아니다. 복잡할 때만 상태도·구체적인 값 추적을 추가하고,
조작이 필요할 때만 시뮬레이션을 제안한다. 매 작업에 퀴즈를 강제하지 않는다. 사용자가 이해
확인을 원하면 한 번에 질문 하나로 진행한다.
