# compare-mockups 검수 기준

항목마다 통과·미통과와 산출물 인용을 답한다. 최종 판정은 사람이 화면을 보고 한다.

| # | 기준 | 통과 조건 |
|---|---|---|
| 1 | 질문이 하나인가 | 비교 화면과 보고가 같은 질문 하나를 말한다 |
| 2 | 비교할 변수만 다른가 | 안마다 데이터·문구·바깥 틀이 같고 갈리는 것이 무엇인지 적혀 있다. 스타일 비교면 데이터와 화면 목적이 같다 |
| 3 | 지어내지 않았는가 | 시안의 기능·수치·문구가 요청이나 입력 파일에 있거나 「예시」로 표시돼 있다 |
| 4 | 안마다 잃는 것이 있는가 | 장점만 적은 안이 없다 |
| 5 | 사용자가 고르는가 | 추천은 있어도 확정했다고 쓰지 않고 고를 것을 묻는다 |
| 6 | 확인하지 않은 것을 밝히는가 | 렌더나 독립 비평을 못 했으면 그렇게 적는다 |

```
#<번호> 통과 | 미통과
근거: "<인용>"
```
