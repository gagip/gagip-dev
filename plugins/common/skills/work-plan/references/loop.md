# 반복 검토 루프

고치고 → 검토받고 → 다시 고치는 일을 두 번 넘게 돌 작업에 쓴다. 리뷰 반영, 문서 검증, 문구·시안 다듬기가 여기에 든다. 계획서에 「한 회차」와 「루프 장치」 두 절을 더하고, 실행 중에는 `scripts/loop_ledger.py`로 회차를 기록한다.

## 한 회차

1. 산출물을 만들거나 고친다.
2. 기계 검사를 전부 다시 돌린다. 바뀐 곳만 돌리지 않는다. 고친 것이 다른 곳을 깨뜨리는 일이 흔하다.
3. 앞 회차 보고를 모르는 새 검토자에게 넘긴다. 넘길 것은 대상 목록, 판정 기준, 심각도 정의, 확정 목록, 범위 밖 목록이다.
4. 지적마다 `loop_ledger.py check`로 판정하고, 「반영 가능」만 반영한다. 반영한 대상은 `change`로 남긴다. 남기지 않으면 다음 회차의 확정 목록이 비어 오락가락을 못 막는다.
5. 장치마다 걸렸는지 `guard`로 남기고 `end`로 회차를 닫는다.

## 루프 장치

기본 장치는 늘 넣는다. 조건부 장치는 조건에 맞을 때만 넣는다.

`guard` 이름 열의 이름을 `init --guards`와 `guard`에 그대로 쓴다. 회차 상한과 확정 목록은 스크립트가 판정하므로 `guard`로 남기지 않는다.

| 막을 일 | 장치 | `guard` 이름 | 넣는 조건 |
|---|---|---|---|
| 끝나지 않음 | 회차 상한(기본 3). 상한에서도 높음·중간이 남으면 멈추고 보고 | (스크립트) | 기본 |
| 오락가락 | 확정 목록. 앞 회차에 바꾼 대상은 높음일 때만 다시 보고, 높음이면 사람이 정한다 | (스크립트) | 기본 |
| 기준이 높아짐 | 심각도 정의를 계획서에 고정. 중간은 "어디서 왜"의 근거 한 줄이 없으면 낮음으로 친다 | 심각도 근거 | 기본 |
| 범위가 번짐 | 범위 밖 지적과 이 작업 수단으로 못 고치는 지적은 「따로 정할 것」으로 모으기만 한다 | 범위 밖 | 기본 |
| 루프 단위 밖을 못 봄 | 루프가 끝나면 다른 단위(브랜치 전체 diff, 문서 전체)로 끝 검토를 한 번 더 한다. 마지막 수정까지 포함한다. 다음 회차를 바뀐 대상만 보게 줄였어도 생략하지 않는다 | 끝 검토 | 기본 |
| 검사 규칙이 좁아 0건 | "위반 0건"을 완료 기준으로 쓰면, 걸려야 할 예문으로 검사가 잡는지 먼저 본다 | 대조군 | 기계 검사가 완료 기준일 때 |
| 못 본 것을 0건으로 셈 | 대상 목록 수와 실제로 본 수를 회차마다 대조. 못 본 것은 미검증으로 따로 센다 | 대상 수 대조 | 대상이 여럿일 때 |
| 검토자가 덜 봄 | 검토자는 보고 첫머리에 실제로 연 대상을 적는다. 대상 목록과 다르면 그 보고를 버린다 | 연 대상 대조 | 대상이 여럿일 때 |
| 비용 불어남 | 1회차 전에 같은 검토 묶음 하나로 비용 줄일 수단(자료 미리 만들기, 검토자 종류 등)을 짧게 비교한다. 판정선은 자료를 보기 전에 정하고, 놓친 지적 수를 먼저, 토큰을 그다음으로 본다. 고른 수단은 그 루프 계획서에만 적는다 | 비용 상한 | 검토자를 셋 넘게 띄울 때 |
| 사람이 정한 것이 바뀜 | 사람이 이미 정한 결정(용어·말투·방향)에 닿는 지적은 반영하지 않고 모아 보인다 | 사람 결정 | 그런 결정이 있을 때 |

## 회차 기록

```bash
L=<작업 폴더>/loop.json
python3 <스킬>/scripts/loop_ledger.py init $L --max-rounds 3 --guards "심각도 근거,범위 밖,끝 검토,대상 수 대조"
python3 <스킬>/scripts/loop_ledger.py start $L
python3 <스킬>/scripts/loop_ledger.py check $L <대상> --severity medium
python3 <스킬>/scripts/loop_ledger.py change $L <대상...>
python3 <스킬>/scripts/loop_ledger.py guard $L "심각도 근거" --fired --note "근거 없는 중간 2건을 낮음으로"
python3 <스킬>/scripts/loop_ledger.py end $L --high 0 --medium 2
python3 <스킬>/scripts/loop_ledger.py report $L
```

`<스킬>`은 work-plan 폴더다. 종료 코드 3은 멈추고 사람에게 올린다는 뜻이다. 대상 이름은 번역 키, 파일 경로, 문서 절처럼 회차가 바뀌어도 같은 것을 가리키는 이름으로 쓴다. `guard`는 안 걸린 장치도 `--quiet`로 남긴다. 사람이 승인한 재변경만 `change --approved`로 남긴다.

## 끝 보고

`report` 표, 끝 검토 결과, 「따로 정할 것」, 미검증 대상, 사람이 볼 지적 모음을 싣는다.
