# 세션 문서

세션 문서는 사용자와 세션이 목표·진행 상태·결정을 주고받는 화면이다. 사용자는 대화창 대신 이 한 장으로
지금 상태와 남은 결정을 보고, 에이전트는 컨텍스트 압축 뒤 이 한 장으로 하던 일을 되찾는다.
서브에이전트·읽기 전용 지시엔 만들지 않는다.

## 만들기

위치는 프로젝트 지침이 정한 세션 문서 경로를 따른다. 정한 곳이 없으면 사용자에게 묻는다. 파일 이름
`YYYY-MM-DD_<세션 목적>.html`.

```bash
python3 <이 스킬>/scripts/session_doc.py new <경로.html> --title "<세션 목적>"
```

뼈대(디자인 시스템 CSS, 고정 칸 세 개)가 생긴다. 이어 쓰는 세션은 기존 문서를 연다. 예전 `.md`
세션 문서는 그대로 이어 쓴다.

## 칸

맨 위 세 칸은 고정이다. id·순서를 바꾸지 않고 그 사이에 다른 칸을 넣지 않는다. 사용자는 어느 세션을 열어도
같은 자리에서 목표와 진행을 보고, 에이전트는 압축 뒤 이 세 칸부터 읽는다.

| 칸 | 담을 것 |
|---|---|
| 지금 상태 `#state` | 상태 표시 하나(`pill run` 진행 중 · `wait` 사용자 답 기다림 · `stop` 막힘 · `ok` 끝)와 한 문장. 지금 하는 작업, 다음에 할 일 |
| 명세 `#spec` | 목표 · 완료 기준(기준마다 증거 종류 하나) · 제약사항 · 비목표 · 검증 수단 · 결과물(절대경로)을 한 줄씩. 착수 전에 채우고 `grill`이 닫을 때 확정한다 |
| 진행 `#flow` | 핵심 작업 흐름의 단계 이름 한 줄. `li.ok` 완료 · `now` 지금 · `wait` 대기 · 표시 없음 남음. 하네스 작업 목록과 같은 단계로 둔다 |

그 아래는 세션 내용에 맞게 짠다. 부품과 쓰는 HTML은 [assets/sample.html](assets/sample.html) 견본에 있다.
흔히 쓰는 칸:

- 사용자가 정할 것: 질문 카드(`.q`), 권장안 `i.rec`, 반론 `.note`. 없으면 칸을 만들지 않는다
- 한 일: `.item`에 문제(실제 값) · 바꾼 것(파일과 무엇, 전/후·코드 발췌) · 확인(명령·캡처와 결과, 못 했으면 "미검증")
- 정한 것: `.decided` 안 질문 카드에 고른 안 `i.pick`, 접힌 「사용자 결정 원문 · 합의와 달라진 점」
- 남은 일: 목록과 이슈 링크
- 시안·그래프·전후 비교: `.compare`, `table`, `figure`

새 모양이 필요하면 부품을 조합하거나 그 칸에 `style` 속성으로 덧붙이고, 여러 세션에서 반복되면
`assets/ui.css`와 견본에 부품을 더한다.

## 지킬 것

- 스크립트를 넣지 않는다. 앱 옆 창은 작업 폴더 밖 파일을 스크립트 없이 정적으로 띄워 탭·버튼이 동작하지
  않는다. 조작해 볼 시안·계산기는 같은 폴더에 따로 HTML을 만들고 세션 문서에 그 절대경로를 적는다.
- CSS는 손으로 고치지 않는다. `<style id="ui">`는 스크립트가 `assets/ui.css`로 덮어쓴다.
- 다른 사람이 읽을 결론 보고는 프로젝트가 정한 작업 보고 위치에 따로 두고, 세션 문서에는 그 경로만 적는다.

## 갱신과 띄우기

갱신 시점: 작업 하나를 끝냈을 때, 사용자에게 묻기 직전, 보고 직전. 고친 뒤 정확히 이 명령을 실행한다.

```bash
python3 <이 스킬>/scripts/session_doc.py sync <경로.html>
```

CSS를 최신으로 바꾸고 갱신 시각을 지금으로 맞춘 뒤 고정 칸·스크립트를 검사한다. `실패`가 나오면 고치고
다시 돌린다. 통과하면 파일 보내기 도구(`display: render`)로 옆 창에 다시 띄운다. 파일 보내기 도구가 없는
하네스에선 경로를 대화에 적는다.

사용자가 고를 것이 생기면 「사용자가 정할 것」을 채우고, 대화창에도 선택지 버튼(누르면 채팅으로 답이 들어오는
위젯이나 하네스의 질문 상자)을 띄운다. 받은 답은 질문 카드를 「정한 것」으로 옮기고 원문을 그 아래 적는다.

## 끝 보고

따로 보고서를 만들지 않는다. `#state`를 `ok`로 바꾸고, 「한 일」에 해결하려던 문제 → 바꾼 것 → 확인한
방법과 결과를, 「남은 일」과 「사용자가 정할 것」을 채워 `sync` 뒤 띄운다. 대화창에는 5줄 안팎 개요와 세션
문서 경로만 쓴다. 짧은 답·파일 하나 수정은 세션 문서 없이 글로 보고한다.
