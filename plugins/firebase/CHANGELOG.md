# CHANGELOG

## [0.2.0] - 2026-09-07

### ✨ Feat
- **crash-triage**: 상위 크래시를 집계에서 시작해 개별 이벤트·스택·코드까지 밀어 근본 원인을 세우고, 각 건이 기존 이슈인지 신규 후보인지 보류인지 판정해 표로 보고하는 스킬을 추가했다. 이슈 생성과 코드 수정은 담지 않는다 (`15aff11`)

## [0.1.0] - 2026-09-07

### ✨ Feat
- 플러그인 신설. 로컬에 설치된 Firebase CLI의 MCP 서버를 읽기 전용 Crashlytics 도구 4개(`list_events`·`get_issue`·`get_report`·`list_notes`)로 좁혀 노출한다. 이슈 상태 변경·노트 작성 같은 쓰기 도구와 다른 Firebase 기능은 싣지 않는다 (`b02252b`)
